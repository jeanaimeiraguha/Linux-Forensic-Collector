What LFC does

LFC is a modular collection utility you run on your own Linux machine, with your explicit authorization, to gather system, filesystem, media, browser, network and software metadata into structured reports you can review before anything leaves the host.

System intelligence

Distribution, kernel, CPU, memory, storage, filesystems, uptime, hardware model.

Filesystem & media inventory

Paths, sizes and timestamps for documents, images, video and audio. Metadata only — no file contents.

Browser security audit

Installation, versions, profiles and allowlisted security settings. Never touches passwords, cookies or tokens.

Network audit

Interfaces, addressing, DNS, connection metadata and firewall status. No packet capture.

Installed software

Packages, versions, running and enabled services from the native package manager.

Structured reports

HTML, JSON, TXT plus filesystem and media CSV inventories and a full audit log.

How it works

  1. Download the collection utility from this page (link below).
  2. Verify the download against the published SHA-256 checksum.
  3. Review the script source if you wish — it is plain Bash you can read.
  4. Execute it yourself from a terminal. Opening this page runs nothing.
  5. Approve the scope when prompted (file metadata scanning is opt-in).
  6. Review the generated reports in the output directory.
  7. Approve transmission only if you want the bundle emailed. Declining keeps everything local.

LFC never executes automatically, never escalates privileges silently, never installs persistence, and never uploads anything without your explicit approval.

Installation & usage

# 1. Extract the archive
tar -xzf lfc-1.0.0.tar.gz
cd linux-forensic-collector

# 2. Run the installer (checks Python 3, prepares config, sets permissions)
./install.sh

# 3. Execute the collector (you run it - nothing runs by itself)
./lfc.sh

# Useful options
./lfc.sh --help                 # all options
./lfc.sh --dry-run              # show the collection plan, execute nothing
./lfc.sh --scope /path/to/dir   # override the scan scope
./lfc.sh --no-send              # generate reports, never transmit
./lfc.sh --verbose              # show audit events live

Requirements: Bash 4.4+, Python 3.8+, standard coreutils. No third-party Python packages are needed.

Security & privacy

What LFC collects

  • System, hardware and resource metadata
  • File metadata: path, size, timestamp, type (opt-in)
  • Media inventory by extension (opt-in, metadata only)
  • Browser install/version/profile locations and allowlisted security settings
  • Network configuration and connection metadata
  • Installed package and service lists

What LFC never does

  • Read, copy or upload file contents
  • Access passwords, cookies, tokens or private keys
  • Capture packets, sniff traffic or intercept credentials
  • Escalate privileges without asking first
  • Install persistence or background services
  • Transmit reports without your explicit approval

Read the full policy in SECURITY.md and the audit trail (audit.log) written with every run.
